Machine Learning / Healthcare AI

PrognosAI

An end-to-end Machine Learning application that transforms raw healthcare data into a deployed AI-powered solution for predicting whether a patient may be at risk of developing a disease.

Live Demo View on GitHub
[01]

Overview

PrognosAI predicts potential disease risk based on its trained model; it does not provide a medical diagnosis. It takes a raw healthcare dataset all the way to a deployed product: cleaned data, a trained model, an API, and a web interface that a non-technical user can actually operate. The result is a deployed risk-prediction application rather than a notebook-only project.

[02]

The Challenge

The project began with raw and inconsistent healthcare data. Before any model could be trained, the dataset needed extensive preprocessing — the data quality problem was the real problem.

[03]

Data Preparation

  • Missing values
  • Outliers
  • Inconsistent formats
  • Text standardization
  • Feature engineering
  • Exploratory Data Analysis
[04]

Machine Learning

The trained model was integrated into a production-style application served by a FastAPI backend, rather than remaining inside a Jupyter Notebook. Predictions are requested by the web app and returned through the API in real time.

[05]

Application

  • Arabic / English interface
  • Dark / Light mode
  • Patient data input
  • AI-powered prediction
  • PDF report generation
  • Arabic PDF rendering

Deployment
